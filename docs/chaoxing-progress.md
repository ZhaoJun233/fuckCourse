## 行为变化

1. 固定一个章节 worker；章内任务也串行，媒体使用 1 倍真实计时，不沿用旧配置的并发/加速。
2. 首次上报当前历史位置，不先跳到完整时长。使用单调时钟，按平台卡片已有 `reportTimeInterval` 的真实秒数间隔上报；缺失/异常时使用现有默认 60 秒。开始事件为 3、播放为 0、结束为 4。
3. 本地计时进度条明确标注“非平台完成”。网络请求/限流等待不累计为本地媒体位置。
4. HTTP 200 不是完成；上报 JSON 必须有布尔 `isPassed`，字符串 `"false"` 等不当作成功。肯定结果需独立 GET 原任务卡并匹配任务与媒体 ID，再确认布尔 `isPassed=true`。缺失或不一致不能成功。
5. 历史位置已到结尾但未通过：保留待办，先核查，不从头自动重播；视频失败也不自动猜测为音频再试。结尾最多 3 次上报，另有媒体总时间预算。
6. 每章完成与课程结束后独立回读章节状态。每次成功回读更新快照，因此正常完成某章后即使稍后中断，也保留该检查时的记录。失败和待办不会发送“全部完成”通知。
7. 同账号、同课程/班级再次读取若已完成标记减少，或已知章节消失，则停止后续学习请求、排空调度队列，不自动重刷。保留此前快照作排查依据。

## 本地记录与隐私

`progress_state.json` 与共享 Cookie 文件同目录。记录 SHA-256 化的账号/课程/班级/章节组合键、完成集合和 UTC 检查时间，不存原始账号、密码、API Key、Cookie、签名或课程标题。记录通过临时文件加原子替换写入；读取损坏、保存失败或回退时不主动覆盖旧记录。此文件已忽略，打包审核拒绝夹带。

首次运行只能建立基线，不能把旧日志自动认定为当前有效完成记录。若经教师/平台确认课程结构已调整，可以先备份本地记录，再手动建立新的基线；不要为了绕过回退告警直接删除排查证据。

## 官方登录在线检测接入（2026-10-09）

用户提供的正常播放网络记录包含 17 次 `/api/monitor` 轮询，间隔 29.994–30.008 秒，响应均为布尔 `status=true`。请求来自官方 `passport2-onlineinfo.js`，轮询使用平台生成的配置、当前登录 Cookie、JSONP 回调和时间戳。它检查登录在线状态，响应拒绝时原生页面会暂停或跳转；没有证据证明它就是次日撤销进度的唯一原因。

同一记录的两张视频任务卡未下发 `supportHeartbeat`、`supportVideoPluginV1` 或 `requestConfigUrl`，普通视频日志间隔为 60 秒；记录未包含 `/multimedia/log/` 请求。因此本次接入的是确认存在的登录检测，不把它冒充为完整视频心跳、观看证明或平台长期验收。

- 使用已获取的官方课程页面签名进入当前章节，限制入口重定向、脚本来源和轮询地址为已核查的超星路径。签名只在内存保留，不使用 HAR 中的历史账号、签名或 Cookie。
- 不执行下载的 JavaScript，只解析已确认的有限配置语法；不认识的脚本、缺失配置、账号上下文不匹配、缺少原生脚本要求的登录 Cookie，均停止。平台明确关闭检测时保留“未启用”状态，不能显示已通过。
- 启用检测时，首次响应确认后才允许媒体上报；媒体等待期间按 30 秒轮询，普通视频日志仍遵守卡片间隔。检测请求等待不计入本地播放位置。
- JSONP 必须匹配本次随机回调，内部对象必须有严格布尔 `status=true`。拒绝、HTTP 异常、超时、协议异常或漏掉完整轮询周期会锁定失败，向现有调度器传播停止信号，排空待执行课程任务；不跟随拒绝跳转、不改状态、不绕过验证码或锁定。
- 原始 HAR 全部 Git 忽略，打包审核禁止包含 `.har`；测试仅使用合成数据。真实记录仅在本地离线验证解析，不重放历史请求，不向平台提交媒体进度。

验收分层：离线测试和真实响应解析可以证明实现符合所捕获的协议；新会话的真实检测是否通过必须以程序收到的平台响应为准；凌晨之后进度是否保留，还必须再看官方完成标记和本地回退快照。未经后两项验证，不能称为跨天回退已彻底修复。

## 验证与限制

离线回归覆盖启动位置、真实计时、配置倍速、独立完成校验、冲突待办、结尾预算、403 停止、Session 复用、哈希隔离、跨运行回退、损坏/空响应、原子保存失败、章/课程最终回读与回退后停止后续请求。真实验证仅使用课程/章节/任务卡的只读请求；未为验收上报学习进度、答题或交卷。

这些改动是减少错误上报和误报成功的保护，不是平台反异常机制的完整实现。计时不证明实际观看，即时回读不证明长期保留，任务完成也不证明答题正确率。已被平台撤销的进度不能靠本地代码或快照恢复；后续是否仍回退需要用户在原生播放器与平台侧记录中核对。
