# 超星直播状态与进度

解析和请求复用 `chaoxing/api/live.py`，调度在 `live_process.py`。状态读取使用现有 `/ananas/live/liveinfo`，累计时长沿用已有 `zhibo.chaoxing.com/saveTimePc`，没有新增远端接口。

字段依据为 [超星官方直播卡片源码](https://mooc1.chaoxing.com/ananas/modules/live/index.html?v=2022-1214-1139) 和 2026-10-09 真实账号的只读响应：

| 字段 | 含义 |
| --- | --- |
| `temp.data.liveStatus=0` | 未开始 |
| `liveStatus=1` | 正在直播 |
| `liveStatus=4, ifReview=0` | 已结束，允许回放 |
| `liveStatus=4, ifReview=1` | 已结束，不允许回放（不是“有回放”） |
| `duration` | 回放总时长，秒；未开播时可能没有 |
| `timeLong` | 平台累计观看时长，毫秒；显示时除以 1000 |
| `timeLongValue` | 累计观看分钟数的显示值；缺少 `timeLong` 时使用 |
| `percentValue` | 平台确认的观看百分比 |
| `ygdate` | 平台提供的预计开播时间，可能为空 |
| 任务属性 `rt` | 完成比例；官方卡片在缺失时默认 0.9 |

用户选择“正在直播只显示进度，保留待办，等回放”。因此未开始、正在直播、不允许回放和尚无回放时长的任务使用 `StudyResult.DEFERRED`，章节调度保留待办、本轮不立即重试。仅实际错误使用失败重试；存在待办或失败时不发送“全部已完成”通知。

可回放任务显示平台进度条，以平台完成比例为成功条件，不从请求次数或本地等待时间推断完成。不使用伪造总时长、随机状态或倍速累计。时长请求之后刷新平台进度；失败、格式未知或连续三次进度未增长会停止。

## 验证边界

真实只读查询确认了一条已结束可回放记录（99.41%）和一条未开始且没有总时长的记录。离线回归覆盖状态分类、数值单位、允许回放标志、请求参数、进度刷新、错误传播、待办队列和结束通知。没有为验证而对真实直播发送累计时长请求；真实新增进度仍需用户在使用时核对平台结果。文档与测试不保存账号、Cookie、推流地址或签名令牌。
